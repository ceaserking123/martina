# About-page photos

The hero portrait and the four-photo strip on the About page work the same
way as the project images — see `public/projects/README.md`.

- Hero portrait: set `heroImage` near the bottom of `lib/data.ts` to a path
  like `/about/portrait.jpg`.
- About page photo strip: add a path to the matching entry's `images` array
  in the `aboutPhotos` list in `lib/data.ts`.
